# 可编辑前端简历 PDF

这是根据 `徐培珊_前端开发_18106505028.pdf` 还原的 React 页面。内容在左侧编辑区实时更新，并使用浏览器原生打印来生成 A4 PDF，保证文字可复制、版式清晰。

## 运行

如本机已安装 Node 18+，执行：

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址后：

1. 在左侧修改内容，或使用“添加/删除”维护技能、经历、项目及职责。
2. 点击“保存”，内容会保存在当前浏览器中，刷新页面后自动恢复。
3. 点击“导出 PDF”，在系统打印对话框中选择“存储为 PDF”。保持 100% 缩放并启用背景图形。

## 主要文件

- `src/main.jsx`：简历数据、编辑器与预览组件
- `src/style.css`：A4 页面、打印和编辑器样式
