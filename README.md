# 可编辑前端简历 PDF

这是根据 `徐培珊_前端开发_18106505028.pdf` 还原的 React 页面。内容在左侧编辑区实时更新，并使用浏览器原生打印来生成 A4 PDF，保证文字可复制、版式清晰。

## 运行

如本机已安装 Node `20.19+` 或 `22.12+`，执行：

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址后：

1. 在左侧修改内容，或使用“添加/删除”维护技能、经历、项目及职责。
2. 点击“保存”，内容会保存在当前浏览器中，刷新页面后自动恢复。
3. 可在“简历模板”中切换经典蓝和简约灰版式。
4. 点击“导入”可先预览 Markdown 或可复制文本的 PDF；仅在点击“应用草稿”后替换当前简历。
5. 点击“导出 Markdown”下载当前内容；点击“导出 PDF”，在系统打印对话框中选择“存储为 PDF”。保持 100% 缩放、启用背景图形，并关闭页眉页脚。

## 主要文件

- `src/data/`：默认简历数据与缓存兼容处理
- `src/components/`：编辑字段、编辑器与简历预览组件
- `src/features/`：Markdown/PDF 导入导出能力
- `src/templates/`：模板注册表
- `src/styles/`：编辑器、简历、弹窗与打印样式
